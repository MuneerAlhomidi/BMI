# 📏 BMI Calculator (Flutter Learning Project)

## 📌 Overview
**BMI Calculator** is a simple Flutter mobile application built as part of a learning course.
It allows users to input height and weight to calculate their Body Mass Index (BMI).
This project was created to practice Flutter fundamentals, UI building, and state management.

> This is a learning project and not a production-ready application.

---

## 🎯 Learning Objectives
This project helped me practice and understand:
- Building user interfaces using Flutter widgets
- Handling user input and state changes
- Applying logic inside Flutter apps
- Structuring a basic mobile project

---

## 🛠️ Tech Stack
- **Framework:** Flutter
- **Language:** Dart
- **Tools:** VS Code / Android Studio

---

## ✨ Features
- User input for height and weight
- BMI calculation based on formula
- Result display with feedback
- Clean and simple interface
